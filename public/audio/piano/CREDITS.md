Auris Docta redistributes 30 unmodified MP3 files from that pinned distribution. It does not redistribute the full 16-velocity-layer SFZ library, release-noise samples, or resonance simulation. Intermediate pitches are repitched during playback; note strength scales attack gain. No endorsement by the original author or the Tone.js project is implied.

`manifest.json` records downloaded file sizes and SHA-256 checksums. Run `node scripts/fetch-piano-samples.mjs` from the project root to reproduce these assets.
